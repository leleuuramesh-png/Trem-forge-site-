# Screenshots dos projetos reais

Coloque aqui os prints/screenshots dos projetos reais que vão substituir os
exemplos placeholder em `templates.html`.

Depois de colocar a imagem aqui, edite o array `PROJECTS` em `templates.html`
e defina o campo `image`, por exemplo:

    image: 'images/projetos/padaria.webp'

Recomendações:
- Formato .webp (mais leve) ou .png/.jpg
- Proporção próxima de 16:9, mínimo ~600x340px
- Se `image` for null, o card usa o emoji + gradiente de fallback
